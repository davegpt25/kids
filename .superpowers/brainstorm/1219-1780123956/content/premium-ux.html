프리미엄 기능, 비가입 사용자에게 어떻게 보여줄까요?

WTP 3가지 심리(시간절약 · 결정불안해소 · 기회손실공포)를 기반한 기능들의 노출 방식

A

🔒 잠금형 — 보이지만 막혀 있음

모든 기능 카드가 보이되, 프리미엄 기능은 자물쇠 아이콘 + 흐림 처리.
클릭 시 "이 기능은 프리미엄 전용입니다" 업그레이드 안내 뜸.

✅ 기대감 자극 ✅ FOMO 유발 ⚠️ 복잡해 보일 수 있음
B

🎯 단계형 — 무료 체험 후 업그레이드 유도

무료 사용자도 1회는 완전히 사용 가능. 2회째부터 "프리미엄으로 계속하기" 게이트 등장.
경험 후 가치를 느껴야 지갑이 열린다는 전략.

✅ 전환율 높음 ✅ 가치 증명 후 결제 ⚠️ 무임승차 가능성
C

📧 이메일 게이트형 — 이메일 등록 = 무료 프리미엄 체험

이메일만 등록하면 모든 기능 7일 무료 체험.
사전예약자 = 자동으로 베타 프리미엄. 지금 흐름과 자연스럽게 연결됨.

✅ 리드 수집 극대화 ✅ 현재 플로우 연장 ⚠️ 수익화 시점 지연
