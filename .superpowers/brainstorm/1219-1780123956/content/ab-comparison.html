A vs C — 어떤 접근이 더 유리한가?

현재 단계(사전예약 랜딩, 미출시)와 한국 학부모 타겟을 기준으로 분석

A. 잠금형
사용자 여정
👀 랜딩 진입
↓
🔒 기능 카드 보임 → "이게 뭐지?"
↓
⚠️ 가치 모름 → 클릭 동기 낮음
↓
❌ 이탈
⚠️ 치명적 약점
잠금형은 이미 가치를 아는 사람에게 효과적.
처음 온 학부모는 "이 앱이 뭘 해주는지"를 모름.
자물쇠 아이콘을 보고 업그레이드할 이유가 없음.
적합한 시점
✅ 앱 출시 이후, 기존 무료 유저 → 유료 전환 유도 시
C. 이메일 게이트형 ⭐ 추천
사용자 여정
👀 랜딩 진입
↓
🎮 시뮬레이션 체험 (지금 있는 데모)
↓
✨ "우와, 이게 다 내 동네 학원이네"
↓
📧 이메일 입력 → 전체 기능 7일 무료
↓
💳 7일 후 구독 전환
✅ 현재 단계에 최적
데모 → 이메일 수집은 이미 구축된 흐름.
이 흐름 끝에 "이메일 = 프리미엄 7일 무료"만 붙이면
전환 마찰 0에 리드 수집 극대화.
적합한 시점
✅ 지금 (사전예약 → 얼리어답터 확보 → 구독 전환)
🏆 최종 제안 — C → A 순차 전략
📍 지금 (사전예약 단계)
이메일 = 전체 기능 무료 체험
목표: 얼리어답터 1,000명 확보
어드민에서 이메일 리스트 + 기능 ON/OFF 관리
🚀 출시 후 (3개월+)
무료 체험 기간 만료 → A 방식으로 전환
사용 이력 있는 유저에게 잠금형은 강력 FOMO
"쓰다가 막히는" 경험이 가장 강한 전환 트리거
